# 字段落库加密 — 密钥管理与运维手册

> 配套方案：`../../.agents/2026-10-19/字段落库加密方案.MD`（§3.5 / §5.1 / §5.2 / §5.3 / §5.5）
> 适用：4.0.0 起 sys_user 手机号/邮箱 PII 落库加密。

## 1. 密钥清单与环境变量

| 环境变量 | 用途 | 规格 |
|---|---|---|
| `FIELD_CRYPTO_DATA_ROOT_KEY` | 数据加密根密钥 dataRootKey，HKDF 派生各代 DEK | Base64(32B)，独立注入 |
| `FIELD_CRYPTO_INDEX_ROOT_KEY` | 索引根密钥，按列 HKDF 派生 IK | Base64(32B)，独立注入 |
| `FIELD_CRYPTO_ACTIVE_DATA_KEY_ID` | 活跃 keyId | `[A-Za-z0-9_-]{1,16}`，禁含 `$` |

- 生产密钥只经环境变量注入，不进代码库、不进常规备份链；prod 配置无字面量兜底，缺失拒启。
- fail-closed 三重拦截（框架 `FieldCryptoStartupGuard`）：缺失/非 32B 拒启；命中 `forbidden-root-keys`
  （仓库已提交的 dev 默认值）拒启；keyId 字符集不合法拒启。

## 2. 密钥托管 escrow（双人共管）

- env 单点丢失 = 全部 PII 密文永久不可恢复，必须有恢复路径。
- 形态：根密钥以 GPG 加密文件（或企业密码管理器加密条目）离线保存；口令/密钥分段双人共管，
  任一人无法单独取回。
- 取用：登记运维审计（时间、事由、执行人）；每季度演练一次恢复。
- rc 清库应急备份（§3.5 步骤 1）：同样双人分段保管，升级验证通过后 7 日内销毁并登记。

## 3. DEK 轮换（建议 1~2 年/次，零停机）

1. 新增 keyId（env 增 `FIELD_CRYPTO_DATA_KEY_ID_K2` + yml `data-key-ids` 增项），切 `active-data-key-id`。
2. 后台批任务按 id 分页扫描旧前缀（如 `k1$`）行 → 解密重加密回写；幂等、乐观重试、限速、抽样校验。
3. 双 keyId 读窗口 ≥ 30 天。
4. **硬闸门**：`SELECT COUNT(*) FROM sys_user WHERE phone_no_encrypted LIKE 'k1$%'`（email 列同查）
   = 0 才允许从配置删除旧 keyId；计数 ≠ 0 一律禁止（漏迁行 + 删 key = 数据永久不可解）。

## 4. 索引密钥（IK）轮换 = 停写重建 runbook

1. 维护窗口停写（或摘除写流量节点）；同步降级检索类接口（尾号搜、全串定位）：重算期间新旧代混杂，
   空结果/假阴性属预期降级，不告警。
2. 配置新 `FIELD_CRYPTO_INDEX_ROOT_KEY`，**同时**将 `helium.crypto.field.canary.allow-overwrite` 置 true
   （单次生效维护开关，覆写动作打审计日志）；轮换完成立即回置 false。
3. 批任务全量重算：解密明文 → 按列派生 IK 重算索引列（masked/密文列不动；同窗口换 DEK 则一并重加密）。
4. 抽样校验；恢复写流量；其余节点正常启动比对 canary 通过。
5. 预计触发周期 3~5 年或泄露应急；canary 双指纹（field-ik / kek-data）任一不匹配即拒启。

## 5. 运维红线

- 改密文列必须同步派生列（masked/盲索引）；DBA 直改派生列 = 红线，写路径必须走应用注解自动填充。
- 显式清空手机号/邮箱只准走应用专用清空方法（`SysUserMapper#clearPiiContact`，四列一并 NULL）。
- AAD、盲索引 purpose、base64 变体（标准字母表+padding，索引恰 24 字符）、截断 128bit：冻结参数，
  禁止原地变更；改名 = 新列新 AAD + 停写迁移。
- UpdateWrapper 局部更新密文列、原生 SQL 直改密文列：禁用（`SysUserCipherColsGuardTest` 静态封死）。
- 生产 JVM 禁 heap dump；actuator 白名单见 application-prod.yml（禁 heapdump/threaddump/env/configprops/beans，
  `show-values=NEVER`）；部署配置漂移进上线检查单。

## 6. dev 默认密钥备案

- `configs/helium-all.yml` 中 dev 默认值已同步登记进 prod 侧 `forbidden-root-keys`（复用即拒启）。
- 如引入 gitleaks 等密钥扫描，将上述两个 dev 值加入白名单备案（仅限 dev/test profile 文件路径）。

## 7. 监控

- `FieldCryptoMetrics`（进程内计数）：GCM tag 验证失败数、加/解密失败数、派生列拒写数。
- tag 失败率异常升高通常意味着密文被篡改或根密钥代际漂移，应配置告警阈值。
